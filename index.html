01 · Web de club · Proyecto real para cliente

Club Atletismo Chapín Jerez

Web completa de un club de atletismo de Jerez de la Frontera, pensada para que socios y familias encuentren horarios, noticias y contacto sin esfuerzo.

Horarios por categoría, calendario y contacto a un par de toques desde el móvil.

Qué incluye

  • Club, horarios por categorías, calendario, noticias, galería de competiciones y contacto.
  • Contacto por email y WhatsApp, mapa del estadio y avisos legales de privacidad y cookies.
  • Diseño responsive para móvil, tablet y escritorio.

Decisiones de frontend

  • Imágenes con srcset, carga diferida y prioridad alta en la portada.
  • Menú móvil con foco atrapado, cierre con Escape y inert cuando está cerrado.
  • Galería sobre el elemento <dialog> nativo, navegable con flechas.

Tecnologías

  • HTML
  • CSS
  • JavaScript

Diseño y desarrollo en solitario, con recogida de requisitos y cambios con el cliente.

02 · Web de restaurante · Sevilla

Antigua Taberna Las Escobas

Web editorial para una taberna sevillana histórica: historia del local, carta por categorías, reservas online y cómo llegar.

Transmitir el carácter del local y llevar a la visita a lo importante (carta, reserva y ubicación) con una navegación sencilla.

Qué incluye

  • Carta en pestañas, con teclas de flecha, Inicio y Fin.
  • Reserva en una ventana modal con el sistema de reservas del restaurante; si falla, el enlace sigue funcionando.
  • Mapa de Google que solo se carga cuando la persona lo pide.
  • Enlace activo según la sección visible y barra de reserva fija en móvil.

Decisiones de frontend

  • Pestañas con roles ARIA y navegación completa por teclado.
  • Mapa y reservas bajo demanda, sin conectar con terceros al cargar.
  • Aparición progresiva y parallax sutil, solo con transform y respetando prefers-reduced-motion.

Tecnologías

  • HTML
  • CSS
  • JavaScript

Web desarrollada por mí.
